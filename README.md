## 📢 Hey, I'm Garreth 

I'm a full-stack developer based in South Africa, and I've been building web stuff for about 20 years now — long enough to have shipped things on ASP Classic back in the day, and recent enough that I'm currently building compliance software with an AI coding assistant as a daily pair-programming partner.

Right now I'm working on a compliance audit system — Clean Architecture backend, one API serving both an Angular web app and a WinForms desktop client, so no logic gets duplicated between the two. 

Before that, I helped build the initial sportsbook for a well-known South African online betting brand — including the bet settlement engine handling thousands of bets per second.


## 🔍 A bit of history
